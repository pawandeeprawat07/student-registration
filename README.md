# 🎓 Student Registration System

A simple and user-friendly Student Registration System built to manage student information efficiently. This project allows users to register students, store their details, and perform basic management operations such as viewing, updating, and deleting student records.

## 🚀 Features

- Student Registration
- View Student Details
- Update Student Information
- Delete Student Records
- Search Students
- Responsive and User-Friendly Interface
- Form Validation
- Clean and Organized Code

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- (Optional) Local Storage / Database
- (Optional) Bootstrap

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/student-registration-system.git
```

2. Navigate to the project folder

```bash
cd student-registration-system
```

3. Open `index.html` in your browser.
